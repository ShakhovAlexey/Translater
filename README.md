# Синхронный переводчик: иврит → русский

Веб-приложение (PWA), которое слушает собеседника на иврите и сразу показывает перевод на русский
текстом и, по желанию, озвучивает его голосом.

## Как это работает

```
микрофон ──► распознавание речи (he-IL, Web Speech API)
               │
               ├─ промежуточный текст (пока человек говорит) ──► быстрый перевод Google ──► серый «черновик» на экране
               │
               └─ законченная фраза ──► перевод выбранным сервисом ──► крупный текст + история + озвучка (ru-RU)
```

* **Черновой перевод** обновляется примерно каждые 0,3 с прямо во время речи, поэтому смысл виден почти сразу.
* **Финальный перевод** делается, когда распознавание закончило фразу (обычно 0,5–1 с после паузы).
* **Голос** — встроенный синтезатор речи браузера, озвучиваются только законченные фразы.

## Переводчики

| Вариант | Цена | Качество | Что нужно |
|---|---|---|---|
| Google Translate | бесплатно | хорошее | ничего |
| MyMemory | бесплатно (лимит в день) | среднее | ничего |
| Claude AI | платно по API (копейки за фразу) | лучшее: учитывает контекст разговора, исправляет ошибки распознавания | API-ключ Anthropic |

При выборе Claude черновики всё равно идут через Google (это быстрее), а законченная фраза
переводится Claude с учётом 4 предыдущих реплик. Модель выбирается в настройках
(Opus 5.5 — качество, Haiku 5.5 — скорость). Если Claude недоступен, автоматически используется Google.

## Где работает

* **Android / Windows / macOS — Google Chrome или Edge** (рекомендуется).
* **iPhone / iPad — Safari** (iOS 14.5+).
* Firefox не поддерживает распознавание речи.

Нужен интернет: распознавание речи в Chrome выполняется на серверах Google.
Микрофон в браузере доступен только по **HTTPS** (или на `localhost`).

## Запуск

Локально:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000 в Chrome
```

В интернете (бесплатно): включите **GitHub Pages** для репозитория
(Settings → Pages → Deploy from a branch → ветка, папка `/`). Приложение откроется по адресу
`https://<пользователь>.github.io/Translater/`, его можно «Добавить на главный экран» на телефоне.

## Советы

* Положите телефон ближе к собеседнику; шум сильно ухудшает распознавание.
* Если включена озвучка и нет наушников, включите в настройках «Не слушать, пока звучит перевод»,
  иначе микрофон будет слышать озвучку.
* Пока приложение слушает, экран не гаснет (Wake Lock).

## Безопасность ключа

API-ключ Anthropic хранится только в `localStorage` вашего браузера и отправляется напрямую в API Anthropic.
Не публикуйте приложение с «вшитым» ключом — для общего доступа нужен небольшой серверный прокси.
